# XHS Skills

High-value skills for Xiaohongshu / RedNote content creation.

## Included

- `selfie-xhs-cover-studio`: turn one selfie and post topic into a 9-cover Xiaohongshu pack with deterministic Chinese text overlays, captions, and reusable creator visual rules.

## Why This Repo Exists

The first skill is designed to sell as a practical creator asset pack, not a vague AI-image prompt. It separates the work:

- image generation handles portrait polish, background, and mood
- deterministic rendering handles Chinese titles, badges, layout, and contact sheets

That keeps the final covers readable and commercially usable.
