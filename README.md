# XHS Skills

High-value skills for Xiaohongshu / RedNote content creation, especially for AI learning, job search, creator tools, and skill sellers.

## Included

- `selfie-xhs-cover-studio`: turn one selfie and post topic into a 9-cover Xiaohongshu pack with deterministic Chinese text overlays, lively cover styles, captions, and reusable creator visual rules.

## Why This Repo Exists

The first skill is designed to sell as a practical creator asset pack, not a vague AI-image prompt. It separates the work:

- image generation handles portrait polish, background, and mood
- deterministic rendering handles Chinese titles, badges, layout, and contact sheets

That keeps the final covers readable and commercially usable.

## First Demo Theme

The default demo focuses on AI learning, job search, and Capafy skill creation. These users already need to publish content about workflows, tools, prompts, job search systems, and build-in-public experiments, so the skill sells a concrete content asset instead of abstract design help.
